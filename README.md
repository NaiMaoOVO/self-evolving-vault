# 自进化知识库（个人实例）

一个可自进化的个人知识库系统：外部资料 → 有证据地蒸馏 → 真实成果 → 反馈捕获 → 规则升级 → 下一轮行为可验证地改变。

> 教程来源：[Rouice《自进化知识库完整搭建教程 v3》](https://mp.weixin.qq.com/s/aZwK8735Tc6hpqYPGqir5g)（施工教材位于 `教程/`，本仓库为其一次完整施工实例）。

## 核心机制

- **本地真相源**：一切知识以本地 Markdown 为准，脱离任何服务可读。
- **GBrain 跨会话记忆**：vault 注册为命名源，新会话先检索再回原文核对。
- **Horizon 外部知识**：RSS 抓取保留来源与时间边界，失败不冒充"无新增"。
- **状态机自动化**：单实例 flock 锁、恢复点续跑、`mechanical_ok` 不冒充正式成功。
- **质量闸门**：15 项检查（`python3 系统/quality_gate.py check`）覆盖资源层零覆盖、secret 扫描、事实判断分离、唯一结案、用户目标高于技术通过等。
- **自进化协议**：单次反馈不改全局；≥2 重复或结果数据才升级；无行为差异不标 evolved。
