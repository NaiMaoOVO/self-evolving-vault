# 02-故障分类表

- 编制日期：2026-08-22
- 编制者：第02章施工子智能体（第二阶段）
- 原则：GBrain 任何故障不得破坏 Markdown 真相源（vault 只读于 import；写入永远只有 vault→brain 单向）

## 1. 权限 / 沙盒

| 项 | 内容 |
| --- | --- |
| 现象 | `command not found: gbrain`；或 import 报路径不可读；或 agent 被禁止写某目录 |
| 诊断 | `ls -la ~/.bun/bin/gbrain`；`echo $PATH`；`ls <vault>` |
| 恢复 | `export PATH="$HOME/.bun/bin:$PATH"`（或绝对路径 `~/.bun/bin/gbrain`）；确认执行者对 vault 只读、对 `~/.gbrain` 可写 |

## 2. 运行时（bun / 二进制）

| 项 | 内容 |
| --- | --- |
| 现象 | gbrain 启动即报运行时错误、版本不兼容（schema pack 与二进制版本错位） |
| 诊断 | `gbrain --version`；`gbrain doctor --fast`；`~/.gbrain/` 下日志 |
| 恢复 | `gbrain upgrade`（notify 模式下先征得用户同意）；升级前备份 `~/.gbrain/brain.pglite`（`cp` 单文件即可） |

## 3. 数据库连接（PGLite）

| 项 | 内容 |
| --- | --- |
| 现象 | 报无法打开/锁住 brain；`doctor` connection 类 FAIL |
| 诊断 | `ls -la ~/.gbrain/brain.pglite`；`pgrep -fl gbrain`（查残留进程持锁）；`gbrain doctor --probe-pglite` |
| 恢复 | 结束残留进程（`pkill -f "gbrain serve"` 前先确认非客户端拉起的 MCP）；损坏时从备份恢复 brain.pglite，再 `import` 重建（vault 是真相源，brain 可全量重建） |

## 4. 导入（import）

| 项 | 内容 |
| --- | --- |
| 现象 | `errors>0`；文件数与 pages 数不符；`No results` 但文件确实存在 |
| 诊断 | 重跑 `gbrain import <vault> --no-embed` 看逐文件统计；`gbrain sources status`；`gbrain list --type note` 与 `ls vault` diff |
| 恢复 | 修正源文件（编码/语法）后重跑增量 import；误删页用 `gbrain put` 或重新 import 恢复 |

## 5. 索引一致性（重命名/重复/失效/噪音）

| 项 | 内容 |
| --- | --- |
| 现象 | 同一内容双命中（新旧 slug 并存）；pages ≠ md 文件数；检索命中已删文件 |
| 诊断 | `gbrain list --type note` ↔ vault 文件清单 diff；`gbrain search <独特关键词>` 看命中数 |
| 恢复 | 按识别→授权→`gbrain delete <旧slug>`→复验流程（详见 `02-刷新协议.md`）；删除属授权红线 |

## 6. embedding（当前禁用，启用后适用）

| 项 | 内容 |
| --- | --- |
| 现象 | `query` 报 `degraded: embed_unavailable`；语义检索不命中；`embed_staleness` 告警 |
| 诊断 | `gbrain config show` 看 embedding_disabled；`gbrain doctor` 看 embedding_column_registry / ze_embedding_health / provider_sunset |
| 恢复 | 当前为**用户决定的预期状态**（非故障）。启用前先修：①维度不一致（声明 1280 vs 列 1024）②provider 迁移（zeroentropyai 托管 API 2026-09-04 关停）→ 按批授权 → `gbrain migrate embeddings --to <p:model> --dry-run` → `gbrain embed --stale` |

## 7. MCP（opencode ↔ gbrain serve）

| 项 | 内容 |
| --- | --- |
| 现象 | opencode 中看不到 gbrain 工具；工具调用超时 |
| 诊断 | 配置在 `~/.config/opencode/opencode.json` 的 `mcp.gbrain`（command 绝对路径）；手动握手：`printf '<initialize 请求>' \| gbrain serve --surface verbs`；`pgrep -fl "gbrain serve"` |
| 恢复 | 修正 command 数组（必须绝对路径 `~/.bun/bin/gbrain`）；**改配置后须重启 opencode**（配置不热加载）；确认未手工常驻 serve 进程占用 stdio |

## 8. 外部 provider（embedding API / 版本检查网络）

| 项 | 内容 |
| --- | --- |
| 现象 | embed 报 401/超时；check-update 无响应 |
| 诊断 | 环境变量 API key 是否存在（不回显值）；代理 `http://127.0.0.1:7897` 是否可用 |
| 恢复 | key 只写环境变量或 `~/.gbrain/config.json`；网络走代理；provider 不可用时检索自动降级为关键词（不会丢数据） |

## 升级流程（跨类别）

任何 `gbrain upgrade` / schema 变更前：`cp ~/.gbrain/brain.pglite ~/.gbrain/brain.pglite.bak-<date>` → 升级 → `gbrain doctor` → 复跑三项标准检索（量子苔藓 / 项目X 预算 / ZEPHYR-7749）确认行为不回退。
