## 未来配置 embedding 时（需用户按批授权）

启用 embedding 后，**每个 chunk 的文本内容**将被发送到所选 embedding provider 的 API：

| 项目 | 说明 |
| --- | --- |
| 发送内容 | 页面切分后的 chunk 全文（即 vault 中 Markdown 的内容片段，含中文正文） |
| 接收方 | 所配置的 embedding provider（默认指向 `zeroentropyai:zembed-1`，其托管 API 2026-09-04 关停，启用前必须迁移，候选见 `02-GBrain配置说明.md`） |
| 发送时机 | `gbrain embed`、`gbrain import`（不带 --no-embed）、query 的查询侧 |
| 成本 | 按 token 计费；启用前用 `gbrain migrate embeddings --to <p:model> --dry-run` 预览 |
| 授权流程 | **每一批内容发送前单独向用户报告 provider、发送范围（哪些文件/chunk）与预估成本，获明确授权后执行**；默认继续 `--no-embed` |
| secret 管理 | provider API key 只写环境变量或 `~/.gbrain/config.json`（git 忽略的本地文件），不写入工程目录、不输出 |

## 边界之外的提醒

- `gbrain serve --http`（含 OAuth/DCR）可把 brain 暴露为远程服务，本工程**不使用**；如未来需要，属"外发"，需单独授权。
- `gbrain sync` 走 git 仓库（可含 remote push），本工程不使用该路线。
- Obsidian 侧：无 Sync/Publish、无社区插件、无 git remote（第01章验收已确认）。
