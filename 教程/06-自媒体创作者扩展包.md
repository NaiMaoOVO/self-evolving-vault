# 06 自媒体创作者扩展包

> Important: 这是职业包模板，不含教程作者的账号、作品、平台数据、商业订单或私人画像。另一个创作者必须用自己的资料重新蒸馏。

## 目标

把通用知识库扩展为"来源→研究→选题→媒介成果→发布反馈→规则升级"的创作者系统。

## 施工提示词

```
请基于我的真实资料生成自媒体创作者包。一、读取范围（用户确认后）- 已发布作品及原稿；- 草稿和被否决稿；- 数据表现；- 评论或受众反馈；- 合作交付与修改记录；- 收藏、关注、学习资料；- 项目经历和商业目标。二、必须生成的画像1. 长期兴趣与收藏画像；2. 项目和真实经历画像；3. 近期关注学习画像；4. 选题偏好画像；5. 表达与媒介风格画像；6. 内容生产方法论；7. 商业布局画像。三、成果路由根据用户实际媒介建立规格，例如短视频、长文、图文、播客、直播、课程；不得假定每个人都有所有媒介。每种媒介定义受众、目的、长度、结构、证据、视觉/声音要求、合规、完成定义和反馈指标。四、选题规则- 每个选题挂原始来源；- 区分事实热度、用户相关性、可演示性、专业可信度、受众价值和商业价值；- 证据不足进入待验证；- 不把旧作品换标题重复生产；- 不虚构实测或个人经历。五、样本- 至少5个黄金样本；- 至少3个反面样本；- 逐项提炼开头、信息密度、结构、证据、表达和结尾；- 区分用户喜欢与实际数据表现，二者冲突时并列记录。六、反馈- 用户评分；- 采用/修改/否决；- 发布后的实际数据；- 商业或项目结果；- 平台合规问题。七、确认所有画像和规则先作为候选，让用户逐条批准；批准后version=1。
```

## 预期路由实例

```
外部资料 → 研究卡 → 候选选题
候选选题 → 画像与证据闸门通过 → 选择媒介 → 草稿 → 用户审阅 → 正式成果
不通过 → 稳定知识 / 待验证 / 明确放弃
发布反馈 → 回流 → 周进化提案
```

## 验证提示词

```
请用3个历史选题回放创作者包：- 一个历史成功题；- 一个失败题；- 一个从未发布但证据充分的题。检查系统是否：1. 给出与历史证据一致的路由；2. 能拦住失败题的已知问题；3. 不虚构实测；4. 能区分媒介；5. 能解释推荐和放弃；6. 不泄露私人或商业敏感信息。若只模仿文风、不能改善选题和成果判断，判FAIL。
```
