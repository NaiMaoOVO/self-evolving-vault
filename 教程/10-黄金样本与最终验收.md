# 10 黄金样本与最终验收

## 黄金运行

用一个隔离场景完成真实闭环：

```
输入：5条真实外部资料 + 2份用户历史资料
→ Horizon抓取并保留来源
→ GBrain可检索
→ 蒸馏为2张知识卡
→ 形成3个候选方向
→ 职业包选出1个
→ 形成1份正式成果
→ 用户给1条负反馈
→ 再出现2条相同反馈
→ 周进化提出规则升级
→ 用户批准
→ 同类任务前后对照
→ 新输出首次生成即避开旧问题
```

## 黄金样本提示词

```
请在隔离测试范围执行黄金运行。每一步保存：- 输入快照；- agent提示词；- 实际输出；- 数量与路径；- 验证结果；- 失败与返工；- 状态变化；- GBrain查询证据；- Horizon来源证据；- 规则升级前后diff；- 同类任务前后对照。禁止手工补写结果冒充系统自动产生。任何降级必须标注。
```

## 独立最终验收提示词

```
你是未参与搭建的独立验收员，只读审计：A 安装：Obsidian、vault、agent权限；B 记忆：GBrain跨会话检索、来源、刷新一致性；C 外部知识：Horizon时间边界、失败真实性、幂等；D 架构：五层职责、模板、原始资料边界；E 个性化：职业包证据、黄金/反面样本；F 生产：最近3轮输入、成果、唯一结案；G 自动化：锁、补跑、中断恢复、状态一致；H 质量：所有闸门坏样本与好样本；I 自进化：反馈→提案→批准→版本→行为差异；J 安全：secret、敏感资料、外发、删除和远端。输出PASS/CONDITIONAL PASS/FAIL、证据路径、无法验证项和最小修复清单。禁止以文件存在、服务在线、命令成功或版本号变化代替用户目标。
```

## 交付门槛

- 黄金运行完整通过。
- 至少一次跨会话记忆。
- 至少一次Horizon失败真实性测试。
- 至少一次中断恢复。
- 至少一次规则升级前后行为差异。
- 所有secret和外发边界通过。
- 新用户只读总导航能说清下一步。

## 仍不能宣称"与原系统完全相同"的情况

- 未使用本人历史资料完成职业包。
- 未真实运行30天。
- 没有发布/业务/学习结果反馈。
- 自动化只做了smoke test。
- 外部服务或平台能力不同。

完成后，系统应被描述为"同等级架构和闭环、属于新用户自己的实例"，而不是复制某个人的知识库。
