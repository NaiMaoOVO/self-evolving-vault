# 07 日常生产闭环

## 目标

每轮新资料都有唯一去向，并形成真实成果、稳定知识或明确放弃。

## 日常运行提示词

```
请执行一轮增量生产。只处理上次成功之后的新资料和未闭环项，不回扫全库。Step 0 预检- 读AGENTS、状态、职业包、上次结案和待验证；- 检查GBrain、Horizon和写权；- 上轮未闭环时先补闭环。Step 1 摄取- 冻结本轮清单；- 记录外部/内部新增数；- Horizon失败写失败，不写无新增。Step 2 蒸馏- 事实、判断、机会、风险；- 来源、日期、置信度；- 冲突和待验证。Step 3 建链- 来源、主题、项目、用途；- 查重后再新建。Step 4 路由- 穿过职业包；- 选择正式成果、稳定知识或明确放弃；- 生成中间草稿不算结案。Step 5 产出- 按成果规格和黄金样本；- 逐条挂来源；- 执行内容质量与合规检查。Step 6 回流- 记录用户采用、修改、否决；- 没有用户反馈时只记录待反馈，不假进化。Step 7 收尾- 写唯一结案；- 更新首页主锚点；- 刷新GBrain；- 轻清理中间态；- 写生长判断和下一步。报告精确数量、路径和失败分类。
```

## 状态报告实例

```
新资料6 / 实读5 / 未读1
知识卡新增2 / 更新1
正式成果1
结案：正式成果
自生长：是，有成果和复用知识
自进化：否，尚无反馈导致规则变化
```

## 验证提示词

```
审计本轮：1. 新增时间边界；2. 冻结清单与实际处理数；3. 每条资料去向；4. 唯一结案；5. 成果到原文的追溯；6. 是否改写资源层；7. GBrain刷新一致性；8. 是否用文件新增冒充生长；9. 是否用反馈日志冒充进化。任一资料悬空、结案冲突或虚构来源均FAIL。
```
