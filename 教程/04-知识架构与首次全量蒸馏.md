# 04 知识架构与首次全量蒸馏

## 目标

建立五层真相源，并用用户真实资料形成第一版稳定知识基线。

## 施工提示词

```
请先访谈需求，再施工。五层顶级目录固定职责：00_资源库：原始证据，只读；01_主题Wiki：稳定知识、方法、案例、Skill；02_项目库：正在推进的问题、项目和决策；03_输出库：可实际使用的正式成果；04_系统维护：入口、规则、画像、状态、反馈和日志。要求：1. 根目录只保留AGENTS.md、首页和收件箱等必要入口；2. 每层最多3个当前需要的二级目录；3. 建原始资料卡、知识卡、项目卡、决策卡、成果卡、反馈卡、进化提案和结案记录模板；4. 字段至少包含title、type、status、created、updated、source、confidence、sensitivity；5. 事实、判断、机会、风险分区；6. 关系至少包括来源、主题、项目和用途；7. 每轮只能结案为正式成果、稳定知识或明确放弃之一。首次全量蒸馏：8. 先只读盘点文件类型、数量、年代、来源、敏感性、重复候选和未读取文件；9. 与用户确认范围后分批处理；10. 每批记录计划数、实读数、未读数、新建/更新知识数、冲突数、待验证数；11. 全文阅读核心样本；抽样必须说明方法和覆盖率；12. 无来源内容降级为假设；13. 冲突并列保存；14. 原始资料不移动、不覆盖；15. 重复知识优先更新既有卡；16. 完成后刷新GBrain并核对索引。
```

## 验证提示词

```
抽查5份原始资料、5张知识卡和2个项目：- 来源是否真实支持事实；- 判断是否被误写成事实；- 适用条件、置信度和敏感性是否存在；- 链接是否有效；- 是否出现同义重复；- 是否记录未读取；- 是否发生资源层写入或原件覆盖；- GBrain能否从知识卡回到原文。任何虚构引用、覆盖原件或"未读冒充已读"均判FAIL。
```
