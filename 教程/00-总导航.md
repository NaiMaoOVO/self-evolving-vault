# 自进化知识库教程v3总导航

> 来源：https://mp.weixin.qq.com/s/aZwK8735Tc6hpqYPGqir5g（Rouice）
> 本文件是唯一施工教材的入口。施工规则以本文为准。

## 完成定义

v3不是"目录和工具都装好了"，而是一个新用户能完成：外部资料进入 → 有证据地蒸馏 → 形成真实成果 → 捕获反馈 → 更新规则 → 下一轮行为发生可验证变化。

## 使用方法

1. 新建空白工作区。
2. 把本教程目录交给Codex、Claude Code、Cursor或其他文件型agent。
3. 每次只执行一章。
4. 上一章验证未通过，不得进入下一章。
5. 任何外发、secret写入、删除、批量移动和数据库迁移均需单独授权。

## 总控提示词

```
请把《自进化知识库教程v3》作为唯一施工教材。当前只执行第【章节编号】章。规则：1. 先读取总导航、当前章节和现有AGENTS.md；2. 先检查前一章验收记录；3. 未通过就停止，不跨章；4. 开工前报告输入、精确写入路径、外部通信和风险；5. 按"需求→设计→实现→测试"完成；6. 教程不提供固定实现代码；你需依据当前官方文档、操作系统和实际路径实现；7. 不输出secret，不覆盖原始资料，不擅自删除或外发；8. 测试必须验证内容和真实行为，不能只看命令退出码；9. 最后生成本章验收记录，写明PASS/CONDITIONAL PASS/FAIL；10. FAIL时停止并留下可恢复状态。
```
