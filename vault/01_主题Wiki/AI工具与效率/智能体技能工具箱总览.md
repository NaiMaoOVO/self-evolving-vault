# 智能体技能工具箱总览

## 适用条件

- 库主（游戏市场运营/海外商品运营双线）在本机 macOS 上调用智能体技能时的选型参考。
- 技能目录会随安装变化：本卡记录 2026-09-02 时点，新增技能应增量更新本卡。

## 事实

- **飞书全家桶（lark-*，约25个）**：doc/base/task/calendar/im/mail/wiki/drive/sheets/slides/minutes/vc(会议)/vc-agent(代开会)/approval/okr/contact/workflow-meeting-summary/standup-report/event/skill-maker/openapi-explorer/markdown/note/whiteboard/shared，统一走 lark-cli。
- **内容创作流水线（baoyu-*，约20个）**：article-illustrator/comic/cover-image/image-gen(多供应商)/infographic/translate/url-to-markdown/markdown-to-html(微信主题)/post-to-wechat/post-to-weibo/post-to-x/slide-deck/xhs-images/youtube-transcript/wechat-summary/compress-image/format-markdown/diagram/electron-extract。
- **调研与抓取**：agent-reach（15平台统一路由，涉及调研/搜索/任何URL时必用）。
- **工程杂项**：release-skills（通用发布流）、rapidocr（本地图片OCR）、grill-me（方案拷问）、baoyu-danger-*（逆向类，需谨慎）。
- **记忆系统**：openviking-memory（harness 级持久上下文，跨会话；与本项目 GBrain 互补——GBrain 管知识库内容，OpenViking 管智能体自身经验）。
- **本项目专用**：gbrain CLI/MCP（长期记忆检索）、horizon（RSS聚合）、state_machine/runner.py（每日轮）、quality_gate.py（15项闸门）。
- **游戏内容运营AI工作台**：本地服务族（hotspot 8790 / comment 8791 / ocr 8787 / llm 8794 / archive 8796 / controller 8793 / xhs-bridge 8805），源码在 Codex/new-chat，见 [[02_项目库/进行中项目/游戏内容运营AI工作台]]。

## 判断

- 【判断】选型口诀：**碰飞书先查 lark-*，做内容先查 baoyu-*，做调研必用 agent-reach，发版用 release-skills**——避免重复造轮子。
- 【判断】lark-doc 与 lark-drive 有明确分工：改文档内容走 lark-doc，动云盘文件/导入走 lark-drive；Base 表格用 lark-base 而非 sheets。
- 【判断】baoyu-danger-* 类技能涉及逆向第三方接口，使用前必须单独向库主确认。
