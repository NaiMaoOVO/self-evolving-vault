# 反馈处理提示词

> 用途：新会话收到用户对【成果】的反馈时，直接按本提示词执行记录与分诊。
> 铁律：除事实错误和安全问题外，一次反馈不得直接改全局画像。

## 提示词正文

记录我对【成果】的反馈，保留原话并拆为：

- 类别：正反馈 / 负反馈 / 缺口 / 结果数据；
- 对象：事实、判断、方法、结构、表达、风险、格式；
- 范围：本成果 / 同类任务 / 全局；
- 强度：一次、重复、结果数据；
- 动作：立即修事实错误、只记录、提出进化提案。

除事实错误和安全问题外，一次反馈不得直接改全局画像。

## 执行步骤（落库口径）

1. 复制 [[04_系统维护/规则与画像/模板/反馈卡模板|反馈卡模板]] 到 `04_系统维护/反馈与进化/反馈卡/`，命名 `反馈-YYYY-MM-DD-对象.md`。
2. 「原话」区逐字保留反馈原文（可脱敏），不改写；解读放「判断」区并标【判断】。
3. 按五维拆解填 对象/范围/强度/动作 分区；正负类别与结果数据写入「事实」区（只写客观内容）。
4. 动作分诊：
   - 事实错误 / 安全问题 → 立即修正对应卡（附修正目标），不触全局；
   - 其余单次意见 → 只记录（status=new/triaged）或转进化提案候选；
   - 禁止依据单次反馈直接修改 规则与画像/ 下任何全局文件。
5. 完成后 status 与动作区同步，等待周进化 review 聚类。

## 判定速查表

| 反馈形态 | 强度 | 允许动作 |
| --- | --- | --- |
| 单次意见（无数据） | 一次 | 只记录 / 提出进化提案 |
| 同一信号 ≥2 次 | 重复 | 可提进化提案（仍需用户批准） |
| 附可量化结果数据 | 结果数据 | 可提进化提案（仍需用户批准） |
| 事实错误 / 安全问题 | 不限 | 立即修该处事实，不触全局 |
