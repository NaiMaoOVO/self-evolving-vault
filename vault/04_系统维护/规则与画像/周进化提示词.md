# 周进化提示词

> 用途：每周固定触发（或主智能体指派）时，新会话按本提示词完整执行一轮进化评审。
> 执行器：python3 系统/weekly_evolution.py review（只读聚类）→ 人工提案 → 用户批准 → apply --approved。

## 提示词正文

读取最近7天反馈、采用/否决成果、画像、方法、模板、Skill和待验证：

1. 聚类信号；
2. 至少重复2次或有结果数据才提出稳定规则；
3. 每项写证据、旧规则、新规则、影响、风险、观察周期；
4. 用户批准前不修改；
5. 批准后只做增量，version+1；
6. 用同类旧任务和新任务做前后对照；
7. 没有行为差异不得标 evolved；
8. 无合格信号就写"本周无可验证进化"。

## 七步执行流程

1. **聚类**：跑 python3 系统/weekly_evolution.py review（读近7天 反馈卡/），输出候选信号表（对象×范围聚类）。
2. **门槛**：仅当同(对象,范围) ≥2 重复或任一附结果数据，才够格提稳定规则。
3. **成文**：对达标信号复制 [[04_系统维护/规则与画像/模板/进化提案模板|进化提案模板]] 到 04_系统维护/反馈与进化/进化提案/，逐项填写 证据/旧规则/新规则/影响/风险/观察周期。
4. **待批**：提案 status=open，等用户显式批准；期间不改任何规则文件。
5. **增量**：批准后 python3 系统/weekly_evolution.py apply <提案> --approved —— 目标规则文件 version+1，提案 open→accepted；不做其他改动。
6. **对照**：用同类旧任务和新任务做前后对照，记录行为差异证据；无行为差异不得标 evolved。
7. **结论**：有行为差异方可标 evolved；无合格信号时本轮周报明写"本周无可验证进化"。

## 铁律核对清单（每次 review 后自检）

- [ ] 单次反馈未改任何全局文件？
- [ ] 升级信号均满足 ≥2 重复或有结果数据？
- [ ] version+1 仅增量、未打包多项变更？
- [ ] 标 evolved 前已有前后对照证据？
- [ ] 无信号时写了"本周无可验证进化"？
