# 成果类型与完成定义

> 四类成果名称为用户访谈确认（2026-08-22）；每类的受众、结构要素、完成定义、验收人、失败定义中，**除红线相关项外均为待确认假设**（基于职业通例推导），待历史成果采样或用户逐条确认后固化。

## 1. 方案计划（活动/策略策划）

- 受众：【待确认假设】直属 leader 与协作部门评审会。
- 结构要素：【待确认假设】背景与目标 → 核心策略 → 活动机制/节奏 → 资源与分工 → 数据指标与预期 → 风险预案。
- 完成定义：【待确认假设】方案通过评审并具备可执行性（目标、指标、分工、时间节点齐备）；数据引用全部带来源与日期（红线，见 [[质量标准]]）。
- 验收人：【待确认假设】直属 leader / 评审会。
- 失败定义：【待确认假设】评审未通过、目标或指标缺失无法执行、数据来源缺失、含合规风险表述（红线）。

## 2. 报表复盘（报告与数据汇报）

- 受众：【待确认假设】团队内部与上级汇报场景。
- 结构要素：【待确认假设】周期概览 → 核心指标达成 → 归因分析 → 问题与改进项 → 下周期计划。
- 完成定义：【待确认假设】所有数字可追溯到数据源与统计口径，结论与数据一致，标注统计时间窗（红线）。
- 验收人：【待确认假设】直属 leader。
- 失败定义：【待确认假设】数字与源不一致、口径未标注、结论无数据支撑、报告晚于使用时点（时效红线）。

## 3. 内容文案（活动/用户触达文案）

- 受众：【待确认假设】玩家（对外）与活动执行团队（对内）。
- 结构要素：【待确认假设】目的与受众 → 核心信息 → 文案本体 → 渠道适配版本 → 合规自查记录。
- 完成定义：【待确认假设】文案通过合规自查（广告法用语、概率公示等，见 [[风险与合规]]）并被采用发布。
- 验收人：【待确认假设】用户本人 + 合规/法务流程（待确认）。
- 失败定义：【待确认假设】含违禁用语或未公示概率、与活动机制不符、逾期未交付（时效红线）。

## 4. 分析报告（行业/竞品/用户舆情分析）

- 受众：【待确认假设】团队决策场景。
- 结构要素：【待确认假设】问题定义 → 信息来源与时点 → 分析框架 → 发现 → 建议；标注信息截止时间（红线）。
- 完成定义：【待确认假设】每条关键论断附来源与日期，信息截止时间明确，建议可执行。
- 验收人：【待确认假设】直属 leader / 会议采用。
- 失败定义：【待确认假设】引用过期信息未标注、来源缺失、结论超出证据、竞品信息误读。

## 共同失败定义（红线，用户访谈确认 2026-08-22）

- 数据准确性失败：任何引用数据无来源或与来源不符。
- 时效性失败：时效敏感内容未标注信息截止时间，或晚于决策时点交付。
- 合规失败：触及版号/未成年人保护/隐私/广告法/概率公示任一风险项而未过检查（范围待确认，见 [[风险与合规]]）。
