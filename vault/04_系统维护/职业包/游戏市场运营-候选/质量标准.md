# 质量标准

> 三条红线为用户访谈确认（2026-08-22）；各检查单的具体条目为从红线展开的候选细则，待历史成果采样验证。本标准用于第07章 Step 5 产出后自检，任一红线项不过则成果不得进 03_输出库。

## 红线一：数据准确性检查单

- [ ] 每个引用数字/市场数据附来源（原始卡 wikilink 或外部链接）。
- [ ] 每个来源附发布/统计日期。
- [ ] 统计口径已标注（时间窗、样本范围、指标定义）。
- [ ] 结论不超出数据支撑范围（无过度引申）。
- [ ] 多源数据冲突时已并列呈现，未擅自取舍。
- 状态：候选细则，待用户历史资料/确认补证。

## 红线二：时效性检查单

- [ ] 时效敏感内容标注"信息截止时间"。
- [ ] 行业/竞品动态的引用不晚于使用时点可接受的时滞（具体阈值待确认）。
- [ ] 周期性报表在约定时间窗内交付。
- [ ] 已知更新数据覆盖旧数据时，旧结论同步修正或作废标注。
- 状态：候选细则，待用户历史资料/确认补证；时滞阈值待访谈确认。

## 红线三：合规检查单（适用范围待确认，见 [[风险与合规]]）

- [ ] 广告法用语自查（"最/第一/绝对化用语"等）。
- [ ] 抽奖/开箱类活动概率公示。
- [ ] 未成年人保护相关表述与机制。
- [ ] 用户个人信息已脱敏，不外传原始数据。
- [ ] 涉及版号状态表述与事实一致。
- 状态：行业通用候选条目，适用范围待确认。

## 用户目标质量高于技术通过

- 技术自检全过 ≠ 成果合格：成果须对照用户目标与（未来建立的）[[黄金样本]] 质量水平衡量；用户认为未达目标即不通过，即使所有检查项通过（对齐第09章质量闸门条款）。
- 在黄金样本建立前，本条以用户逐次反馈为准，不得以"检查单全过"替代用户验收。
