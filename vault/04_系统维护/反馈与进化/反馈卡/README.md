# 反馈卡目录

用途：存放用户对成果/流程/工具的反馈卡（复制自 `04_系统维护/规则与画像/模板/反馈卡模板.md`）。

命名约定：`反馈-YYYY-MM-DD-对象.md`（如 `反馈-2026-08-22-分析报告结构.md`）。

处理流程：
1. 反馈卡创建后 status=`new`。
2. `系统/weekly_evolution.py review` 读取本目录近 7 天反馈卡，按 (对象,范围) 聚类输出候选信号表。
3. 单次反馈只记录/候选；≥2 重复或附结果数据才可提稳定规则（见 `规则与画像/进化协议.md` 铁律二）。
4. 转为进化提案后 status=`converted` 并附提案 wikilink；忽略的 status=`dismissed` 并附理由。

铁律：单次反馈不得直接改全局画像/规则（进化协议.md 铁律一）。
