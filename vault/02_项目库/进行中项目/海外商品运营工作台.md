# 海外商品运营工作台（merch-ops-workbench）

## 项目定位

面向跨境电商商品运营的**本地优先**日常分析工作台：导入 Excel/CSV → 字段映射 → 多表匹配 → 指标分析 → 异常诊断 → 任务/问题闭环 → 多格式周报导出。AI 仅作脱敏后的辅助假设。

- GitHub：`NaiMaoOVO/merch-ops-workbench`（main 分支，CI=测试+构建）
- 飞书 SOP 教程页：https://my.feishu.cn/wiki/BxzKwBh7iiazwkkRbOicNOaZnoh

## 踩坑记录（重要！）

1. **lark-cli 授权**：用户身份刷新令牌过期 → bot 无法访问个人 wiki。设备码 10 分钟过期且**重新发起会作废上一条**。曾长期失败的真因之一：沙箱禁止写 `~/.lark-cli/`，令牌存不下来——需 sandbox_permissions 提权。最终解法：用户在自己终端跑 `lark-cli auth login --scope '...'`（原生阻塞等待，无过期压力）。
2. **npm 沙箱 EPERM**：`~/.npm/_cacache` 写入被拦 → 本地复现 CI 行为时用 `npm_config_cache=$PWD/.npm-cache`。
3. **lockfile 陷阱**：手改 package.json name 后必须同步 package-lock.json 两处 name；npm11 dry-run 不报错而 npm10(CI) 抛 Invalid Version。
4. **run_code 高频错误**：edit 后未 re-read 就再 edit（guard 拒绝）；多行字符串用 array.join('\n')；grep 正则中方括号要转义；bash 参数漏 description 会报错。
5. **飞书文档写入**：markdown 导入用 `--content @file`（仅相对路径）；尖括号文本会被当 XML 标签解析，先改写为中文引号。
