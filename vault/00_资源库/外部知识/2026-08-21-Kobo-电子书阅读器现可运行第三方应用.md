# Kobo 电子书阅读器现可运行第三方应用

## AI 摘要（Horizon 日报）

Cobalt 项目使 Kobo 电子书阅读器能够运行第三方应用，为用户提供了新的定制可能性。该项目目前处于早期阶段，存在设备兼容性限制，例如不支持 Clara Colour 和 Clara BW 等单核设备。社区中已有类似解决方案，如 NickelMenu 和 PostmarketOS，但 Cobalt 提供了不同的应用开发途径。

**「背景」** Kobo 是加拿大公司 Rakuten Kobo 生产的电子书阅读器系列，其设备通常运行基于 Linux 的专有操作系统，用户界面称为 Nickel。由于系统相对封闭，社区开发了多种增强工具，例如 NickelMenu，它允许用户通过菜单集成自定义功能，而无需替换整个系统。此外，一些 Kobo 设备还可以运行 PostmarketOS 等替代操作系统，从而获得更广泛的 Linux 应用支持。Cobalt 项目旨在进一步开放 Kobo 平台，允许第三方应用直接在设备上运行，但可能受限于特定硬件型号。

**「影响」** 对于希望扩展 Kobo 设备功能的开发者而言，Cobalt 可能带来新的应用生态，但受限于设备兼容性，初期影响范围有限。

**「社区讨论」** 社区成员提到 NickelMenu 作为现有解决方案，并提醒注意设备核心数；也有用户对 Cobalt 表示兴趣，但发现其不支持 Clara Colour 等设备。

Cobalt is an open-source application platform for Kobo e-readers: a launcher, a signed App Store, a Rust SDK, and a runtime that keeps every app in its own unprivileged process.
Install it once over USB. Every app after that installs, updates and removes on the reader itself, over Wi-Fi. A reboot returns to the stock Kobo reader.
Every app is a static ARM binary running as its own unprivileged process on stock hardware. The App Store installs, updates and removes them over Wi-Fi, with signatures verified before anything launches.
