# 停止制作 TUI：编码代理让原生 UI 成本骤降

## AI 摘要（Horizon 日报）

Thomas Ptacek 在博客中主张，即使是个人使用的小工具，也应构建真正的原生用户界面，因为编码代理已将可用 GUI 的开发成本降至几乎为零。Simon Willison 对此表示赞同，并提到自己早在三月就通过 vibe-coding 创建了 macOS 任务栏应用，用于监控带宽和 GPU，至今仍每日使用。Willison 承认自己尚未习惯为其他项目制作原生 UI，但认为已没有借口不这样做。Ptacek 建议开发者尝试将废弃的 CLI 工具转化为原生应用，并认为这可能会改变他们的思维方式。

**「背景」** 终端用户界面（TUI）长期以来是开发者构建个人工具时的常见选择，部分原因是图形用户界面（GUI）的开发成本较高。然而，随着编码代理（coding agents）等 AI 辅助开发工具的普及，构建原生 GUI 的成本已大幅降低。Thomas Ptacek 在 2026 年 8 月 20 日的博客文章《Stop Making TUIs》中提出，开发者应利用这一趋势，为即使是微小的个人工具也构建原生用户界面，而非继续依赖 TUI。Simon Willison 在 2026 年 3 月曾通过“vibe-coding”方式构建了 macOS 任务栏应用，并持续使用至今，这为 Ptacek 的观点提供了实践例证。

**「影响」** 对于习惯使用 CLI 或 TUI 的个人开发者，这一观点可能促使他们利用编码代理快速构建原生 GUI，从而提升工具易用性和开发体验。

Stop Making TUIs. Thomas Ptacek advocates for building real native user interfaces for even the smallest of personal tools, because coding agents have reduced the cost of getting a usable-enough GUI up and running to almost nothing.
